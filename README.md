## Проектная работа 3 спринта

## Задание 1

В директории Task1 должны лежать карта IT-ландшафта и схема интеграции приложений с пользователями.

## Задание 2

В директории Task2 должна лежать таблица с требованиями по группам FURPS+ в формате Markdown.

## Задание 3

В директории Task3 должен быть ADR в формате Markdown, который описан по шаблону.

## Задание 4

В директории Task4 должен быть ADR в формате Markdown, где описано архитектурное решение для нового кейса, набор задач для каждой системы из ADR нового кейса и RoadMap реализации по шаблону.

## Задание 5

В директории Task5 должен быть ADR в формате Markdown с описанием функциональных и нефункциональных требований, диаграммы контекста и компонентов C4, описание альтернативных решений и ограничений вашего решения.
